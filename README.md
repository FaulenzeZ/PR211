# Практическая работа 2.1.2 — Рефакторинг кода (разбиение на функции)

## Вариант

Вариант 8. Фиксация проезда автомобилей

### Исходное задание (2.1.1)

Разработать программу, формирующую программный объект на основании его
описания в виде текстовой строки. В строке задаётся тип объекта и его
свойства. Свойства могут иметь различные типы данных (целый, дробный,
строковый, дата, время). Строковые свойства выделяются кавычками. Дата
описывается в формате `гггг.мм.дд` без кавычек. Свойства отделяются друг
от друга группой из одного или более пробелов.

Тип объекта по варианту: Фиксация проезда автомобилей — свойства:
дата, номер автомобиля (строка в характерном формате).

### Задание 2.1.2

1. Добавить поддержку 2 новых типов объектов, связанных с исходным,
   с новыми полями разных типов.
2. Добавить возможность обработки набора объектов из строки или файла.
3. Улучшить программу: разбить код на простые функции, соблюдая
   принцип SRP. Каждая функция — не более 10 строк.

## Соглашение о кодировании

Код оформлен в соответствии с Google C# Style Guide.
